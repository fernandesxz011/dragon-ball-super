# Dragon Ball Super — Etapa 01 para o Codex

## Como usar
1. Extraia este ZIP em uma pasta do seu computador.
2. Abra essa pasta no VS Code e no Codex.
3. Copie o conteúdo de `prompts/01_Preparacao_e_Base.md` e envie ao Codex.
4. Confira a base visual no navegador antes de iniciar outra etapa.

Este pacote contém SOMENTE a primeira etapa e as cinco imagens originais. Não contém um site implementado, modelos 3D ou personagens separados em camadas.

## Objetivo desta etapa
Preparar o projeto e construir uma base estática navegável fiel às referências. A experiência final será uma apresentação das sagas pela rolagem, com Motion e Three.js nas etapas seguintes.

## Direção visual definida pelas imagens
- Fundo preto e azul profundo, com energia azul e violeta.
- Personagens e cenários ocupam grande parte da tela.
- Títulos fortes, texto curto, espaços de leitura e composição cinematográfica.
- Faixas de sagas inspiradas no layout 03 e nos panoramas 04 e 05.
- Evitar aparência de painel administrativo, excesso de cards e efeitos decorativos em todas as áreas.

Os panoramas são imagens únicas. Recortar uma banda não separa personagens, cenário ou aura. Parallax independente de personagens exigirá novos assets em camadas. Manter os cinco originais intactos; recortes são derivados.

## Conteúdo e posicionamento
Apresentação conceitual de fã do remake e da continuação. Não afirmar que há anúncio, data de estreia ou produção confirmada sem fonte oficial verificada. Black Freeza é um tema visual proposto para o encerramento; não apresentar automaticamente como nome de uma saga oficialmente anunciada. A ordem das seções é editorial e não constitui confirmação de cronologia de adaptação.

## Skills
Nesta etapa, seguir as skills de design de interfaces e testes de navegador que já estiverem disponíveis no seu Codex. Não é necessário instalar skills para começar. Uma skill específica de Three.js pode ser avaliada quando chegarmos ao 3D. Não instalar automaticamente skills externas; conferir origem e instruções antes. Motion e Three.js são bibliotecas, não skills.
